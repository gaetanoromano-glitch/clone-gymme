I file che iniziano con "_" (come questo) NON vengono pubblicati.
Per creare un articolo: copia questo file, rinominalo con lo slug desiderato
(es. `come-fidelizzare-i-clienti.md` → /blog/come-fidelizzare-i-clienti) e scrivi in Markdown.

Campi:
- title, description, date, category sono obbligatori.
- updated: data dell'ultimo aggiornamento importante (facoltativo, default = date).
- author: facoltativo, default "Redazione gymme".
- professional: facoltativo, uno tra personal-trainer | nutrizionista | osteopata.
  Collega l'articolo alla landing di quella professione nel box finale.

Consigli:
- Apri con 2-3 righe che rispondono subito alla domanda del titolo.
- Usa titoli ## formulati come domande reali ("Come...?", "Perché...?").
- Niente numeri o statistiche senza una fonte verificabile.
